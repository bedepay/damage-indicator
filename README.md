# DamageIndicator

Современный индикатор боя для **Paper 1.21.11**.

Возможности:

- красивые парящие цифры урона, лечения и критического урона;
- игрок не видит индикаторы над собственной головой;
- bossbar для атакованного игрока или моба;
- компактный bossbar показывает только имя цели, здоровье и цветной последний урон;
- цвет полосы меняется от зелёного к красному;
- русские тексты и настройка оформления через MiniMessage;
- только Paper API и Adventure — без NMS, базы данных и legacy-модулей.

## Сборка и установка

1. Выполните `gradlew.bat build` на Windows или `./gradlew build` на Linux.
2. Скопируйте `build/libs/DamageIndicator-2.0.2.jar` в папку `plugins` сервера Paper 1.21.11.
3. Перезапустите сервер.

## Команда

- `/damageindicator reload` — перечитать `config.yml`.
- Право `damageindicator.reload` по умолчанию доступно операторам.
